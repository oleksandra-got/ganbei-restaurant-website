# GanBei – Restaurant Website Redesign
A personal learning and portfolio project focused on redesigning and implementing a modern website for the restaurant GanBei.
## About the Project
This project is a personal learning project focused on redesigning the website of the restaurant GanBei.
The goal was to create a modern, visually appealing and user-friendly website while maintaining its existing brand identity.
## Design Features
- Custom website layout and visual design
- Structured page sections and navigation
- Responsive layout for different screen sizes
- Reservation modal window
- Interactive elements using JavaScript
## Technologies
* **Design:** Figma 
* **Frontend:** HTML, CSS, JavaScript
